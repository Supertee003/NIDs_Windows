## 1. ภาพรวม Operator Interface

AEGIS มี operator interface หลายรูปแบบ:

| Interface | ภาษา | Path | สถานะ |
|---|---|---|---|
| **aegisctl** (CLI) | Python | `tools/aegisctl.py` | CANONICAL |
| **aegis_console** | Python | `scripts/aegis_console.py` | CANONICAL |
| **Go Nose TUI** | Go | `nose/main.go` | CANONICAL |
| **Mouth (DEFCON)** | Rust | `mouth/` | OPTIONAL |
| **Dashboard** | Rust (egui) | `aegis_dashboard/` | OPTIONAL |
| **Script Collection** | PowerShell/Python/Batch | `scripts/` | CANONICAL |

## 2. aegisctl — Primary CLI Tool

### 2.1 Architecture

```
tools/aegisctl.py (43 KB)
    │
    ▼
Named Pipe Client
    │ JSON over \\.\pipe\aegis_control_t1
    ▼
Zig Runtime (Control Pipe Server)
    │
    ▼
Command Execution + Response
```

### 2.2 Available Commands

```powershell
# Status & Health
python tools\aegisctl.py status            # Runtime status
python tools\aegisctl.py health            # System health check
python tools\aegisctl.py metrics snapshot  # Performance metrics

# Rules Management
python tools\aegisctl.py rules list        # List loaded rules
python tools\aegisctl.py rules reload      # Hot-reload Rules.json

# Incident Management
python tools\aegisctl.py incidents list    # List active incidents

# Federation
python tools\aegisctl.py federation        # Cluster status

# Daemon Control
python tools\aegisctl.py start            # Start daemon
python tools\aegisctl.py stop             # Graceful shutdown
python tools\aegisctl.py restart          # Restart daemon
python tools\aegisctl.py version          # Version info

# Logs
python tools\aegisctl.py logs tail        # Tail log files

# Backup
python tools\aegisctl.py backup           # Backup config
python tools\aegisctl.py restore          # Restore config
```

### 2.3 Quick Alias

```powershell
# scripts/aegis.bat — quick launcher
scripts\aegis.bat status
scripts\aegis.bat health

# scripts/aegis.ps1 — PowerShell wrapper
.\scripts\aegis.ps1 -Command status
```
