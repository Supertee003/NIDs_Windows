## Flow contract

**Old flow:** Zig stop → C stop controller → wait 5 seconds without checking result → close thread handle/free properties → Zig reports stopped regardless of native result.

**New flow:** Zig stop marks the adapter non-running → C serializes lifecycle and disables callback under its lock → stop ETW controller → if controller stop fails, close the consumer trace handle to unblock `ProcessTrace` → confirm consumer thread exit → only then close handles/free properties → return status → Zig reports errors to diagnostics and worker health.

**Invariant:** No ETW callback can begin after stop has disabled the callback under the callback lock; no consumer-owned handle or session properties are freed until the worker has signalled termination.
