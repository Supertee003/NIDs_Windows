# S1-04 — control-plane mutation authorization

**Patch ID:** CONTROL-AUTH-001
**Flow ID:** FLOW-CONTROL-AUTH (pipe accept → impersonated role → command contract → authorize → dispatch → audit)
**Target HEAD:** `9e0d8626c647e6362244e64064ed9ebd195471b7`
**Date:** 2026-11-10
**Evidence level:** E2 (`zig build test` exit 0) + E1 for the packaging ACL line. No E5; the live daemon still runs the previous image.

---

## 1. Defect (from SYSTEM-SURVEY-001, S1-04)

Three facts composed into a live path for a non-elevated local user to change
what the product detects:

| Element | State before |
|---|---|
| control pipe DACL | `D:P(A;;GA;;;SY)(A;;GA;;;BA)(A;;GA;;;AU)` — any authenticated user may connect and send **any** command |
| caller role | elevation-only: `TokenElevation` → `.privileged`, otherwise `.operate` (`win32_pipe.zig:154-175`) |
| `rules.reload` contract | `required_role = .operate` (`protocol.zig:222`) |
| rule file | `configs\Rules.json` → `Authenticated Users: Modify` |

Net: edit `configs\Rules.json`, send `rules.reload` over an unelevated pipe
connection, and the running daemon applies the modified detection content.

## 2. Chosen solution

Keep the pipe open to authenticated local users (read/status/health/queue keep
working without a UAC prompt — every operator script and every evidence probe
depends on that), and make the **authorization table** the boundary:

1. `rules.reload` now requires `.privileged` (`src/control/protocol.zig:222`).
2. A table-wide invariant test asserts **every** command with
   `is_mutation = true` requires `.privileged`, so a future mutation cannot be
   added at `.operate` without failing the build.
3. `Authorization` already records `caller_role` **and `caller_pid`** in the
   audit row (`handler_registry.zig:207-218`); the survey's claim that identity
   was missing was wrong and is corrected in the survey document.
4. Packaging closes the file half: `$INSTDIR\configs` is ACL'd at install to
   SYSTEM + Administrators full, Users read-only (`tools/installer.py`, `icacls
   /inheritance:r` with locale-independent SIDs).

## 3. Old flow → new flow

```
OLD (non-elevated local user):
  pipe connect (AU:GA) → role=.operate → rules.reload allowed → reloadRules()

NEW (non-elevated local user):
  pipe connect (AU:GA) → role=.operate → rules.reload DENIED (AUTH_DENIED,
  audit row: command=rules.reload role=.operate pid=<caller> ok=false)
  status/health/queue/events  → still allowed (read-only surfaces)

NEW (elevated caller):
  pipe connect → role=.privileged → rules.reload allowed → reloadRules()
```

## 4. Files changed

| File | Change |
|---|---|
| `src/control/protocol.zig` | `rules_reload.required_role = .privileged`; contract test updated; new invariant test over the whole command table |
| `src/control/authorization.zig` | "operate can reload" test replaced by "operate cannot reload" |

In scope: authorization level for detection-content mutation + install-time ACL
of the config directory.
Out of scope (tracked, not fixed here): the pipe has no nonce/freshness replay
check (`protocol.zig:282` declares `nonce`, dispatch never reads it) while
`src/policy/control_ipc.zig:259-349` implements a `(request_id, nonce)` table.
That asymmetry is a separate slice; it does not change the elevation boundary
fixed here. The dev host's repository checkout (`D:\NIDs_Windows\configs`)
remains user-writable until the host window applies the same ACL — the service
currently resolves its config root to the repo, which is itself an open
deployment-layout question (SYSTEM-SURVEY-001 §9.4).

## 5. Invariant

No command with `is_mutation = true` is reachable at a role below `.privileged`.
Read-only commands remain reachable at `.read` on the authenticated pipe, so
monitoring does not require elevation.

## 6. Verification

```

```

Tests that pin the rule:

* `authorization.zig: "Authorizer: operate role cannot reload detection rules"` → deny
* `authorization.zig: "Authorizer: privileged role can do everything"` → allow
* `protocol.zig: "contracts: read-only commands have correct role"` → `.privileged` for reload
* `protocol.zig: "contracts: every mutation requires an elevated caller (S1-04)"` → iterates every `Command` enum member

`zig-out/bin/aegis_nids.exe`. Until then an unelevated `rules.reload` still
succeeds on this host. This record claims E2 only.
