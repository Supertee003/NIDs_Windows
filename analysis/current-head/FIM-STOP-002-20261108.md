# PATCH-FIM-STOP-002 — Preserve and report failed native watcher stops

## Patch declaration

- **PATCH-ID:** FIM-STOP-002
- **FLOW-ID:** REL-003 / DATA-001 (service shutdown → FIM worker → native watcher owner)
- **TARGET HEAD:** `576d8bd`
- **TARGET SOURCE COMMIT:** `c762deb`
- **TARGET FILES:** `src/windows/fim.zig`, `src/pipeline/telemetry_threads.zig`
- **TARGET SYMBOLS:** `FimWatcher.stopAll`, `FimWatcher.deinit`, `fimThread`
- **IN SCOPE:** Propagate nonzero `aegis_fim_stop` results, retain failed native handles for retry, and mark FIM worker failure when teardown cannot be confirmed.
- **OUT OF SCOPE:** Native cancellation algorithm, FIM event parsing/coalescing, driver behavior, service recovery, installation, and historical crash attribution.
- **CONTRACT IMPACT:** A successful native stop removes its handle. A failed stop keeps the handle in the watcher so a later cleanup attempt can retry; the FIM worker logs and reports a failed teardown.
- **ABI IMPACT:** None; existing `aegis_fim_stop(handle) -> c_int` contract is consumed as intended.
- **AUTHORITY IMPACT:** None; Zig owns the watcher and worker-health state; C owns native session memory until stop succeeds.
- **STATE IMPACT:** Failed handles are no longer silently forgotten. Watcher readiness is cleared at worker exit and stop failure is reflected in worker health.
- **TEST IMPACT:** Injected stop callback verifies successful handles are released and failed handles remain owned for retry. Full Zig suite/build required.
- **EVIDENCE IMPACT:** E2 source/build/unit evidence; installed-service Page Heap and start/stop E5 remain open.

## Flow contract

- **OLD FLOW:** C stop failure → native session intentionally retained → Zig ignores the result and clears all handle slots → no retry path and no worker-health failure.
- **NEW FLOW:** C stop result checked → successful sessions removed → failed handles compacted and retained → FIM worker logs and marks failure → owner can retry during final deinit.
- **INVARIANT:** A native handle is cleared from Zig ownership only after `aegis_fim_stop` returns success.
