## 2. PACKAGING-GATE-001 — the defect D1 exposed

The first install of the new bundle **made the host worse**: it replaced a
Valid-signed kernel driver with an unsigned build output, and it never shipped
the minifilter at all.

| Path | Signature before/after first install |
|---|---|
| `build\x64\wfp\aegis_wfp.sys` (packaged) | `NotSigned` |
| `C:\Program Files\AEGIS NIDS\drivers\aegis_wfp.sys` after install | `NotSigned` (was `Valid`) |
| `build\x64\wfp\aegis_wfp.sys.bak-pre-rebuild` | `Valid` |
| `C:\Program Files\AEGIS NIDS\drivers\aegis_minifilter.sys` | **missing** (never packaged) |

Consequences, all of which would have looked like success:

- The installer reports "Installed AEGIS NIDS" and exits 0 while shipping a
  driver the kernel loader will refuse.
- `sc start` would fail with a signature error, which reads like "the driver is
  broken" rather than "the bundle is wrong".
- The minifilter half of the capture path cannot be deployed from a bundle at
  all, so any D2 result would have covered only WFP.

### 2.1 Repair

1. Test cert `00E92849867308596564D134BB981EF726798E97` (CN=AEGIS NIDS Test
   Signing) present in `Cert:\CurrentUser\My`; `signtool.exe` present under
   Windows Kits 10.0.28000.0.
2. `scripts/sign_wfp_driver_20261024.ps1 -ExpectedUnsignedSha256 2ECE7D52…C71C`
   → signed `06CC8E238B79BEC3782F4036BACF058D6B5291B030E59D061FD692F82FB96B50`,
   status `Valid`.
3. `scripts/minifilter_sign.ps1` → `aegis_minifilter.sys` status `Valid`
   (signer `60B05537FEB7A40D6F6624FF5C005C09DC245A63`, CN=AEGIS Test Signer),
   hash `10C41E8043EE08E0F7C51D7ABF0F157FDCC83836B85DD7D45013B2BAE60A21BB`.
4. `scripts/package_release.ps1` now (a) refuses to package any driver whose
   Authenticode status is not `Valid`, naming the sign script to run, and
   (b) packages `build\x64\minifilter\aegis_minifilter.sys`.
5. Re-packaged (`…_021734.zip`), reinstalled: both installed drivers `Valid`,
   `runtime` parity still `MATCH`.

The host was never left with the unsigned driver: the signed backup was copied
back before the corrected bundle was installed.
