## 3. Risk register

Each risk carries a detection signal, a mitigation, the slice that closes it,
and an exit criterion. **A risk with no closing slice is a planning defect, and
a risk with no exit criterion cannot be declared closed.** The mapping table in
section 3.3 is the completeness proof.

### 3.1 Severity and status vocabulary

- Severity: `S1` silent wrongness or data loss, `S2` blocked proof, `S3` drift
  or friction.
- Status: `OPEN`, `MITIGATED` (mechanism in place, proof pending), `CLOSED`
  (exit criterion met and recorded).

**PACKAGING-GATE-001 (new, found by D1, fixed):** the first bundle carried
`build/x64/wfp/aegis_wfp.sys` while it was `NotSigned`, so the installer
replaced a Valid-signed driver with one the loader rejects, and no minifilter
was packaged at all — both while the installer printed success. The build
outputs are now signed before packaging, `package_release.ps1` refuses any
driver that is not `Valid` (naming the sign script), and both drivers are in
the artifact list. Pinned by `tests/tools/test_package_signature_gate.py`.
The WFP audit itself is reproducible: `tools/wfp_filter_audit.py` reduces a
`netsh wfp show state` dump to counts and `--require-no-block` fails on a
blocking AEGIS filter.

**READINESS-001 (new, found after install, procedural fix):** the daemon was
started by the installer while the WFP driver was still Stopped. `daemon.zig`
evaluates `bridge_init.allActive()` once and transitions to `.degraded`, which is
never re-evaluated — the deployed host therefore advertised `DEGRADED` while all
seven subsystems reported RUNNING. Restarting `AegisNids` with both drivers up
gave `state: RUNNING`, `Npcap capture loop starting`, rule 2 matching on registry
writes, and 18,838 events with 0 drops in 25 s. The engineering smell is the
one-shot evaluation, not the order: a bridge that appears later should move the
state machine, not require a restart. Recorded as a runbook order requirement in
`HOST-WINDOW-001`.

**KIND-ATTR-001 (new, found while reading the D3 attribution, not fixed):**
`minifilter_reader.submitRecord` creates events with `canonical.create(.minifilter)`
(`event_type = .custom`) and `event_queue.pushDecodedFrame` maps `.custom` to
`.packet_captured`; no branch of that switch produces `.fim_change`. In the heavy
burst 300,992 of 300,995 `capture_fim` events were therefore counted and
 delivered as `packet_captured` — file paths inside network-packet events — while
the ETW lane tagged the same churn `fim_change`.

Why it was not repaired in this patch: mapping `.minifilter` to `.fim_change`
would add a second duplicate FIM stream to every correlator and rule keyed on
`fim_change` (the ETW lane already supplies it). That is the same
loss-versus-duplication decision as #29, so it needs the owner's call, not a
silent change. Options: (a) retag minifilter records and deduplicate against the
ETW lane, (b) retag and stop the ETW FIM lane, (c) leave the kinds split but
rename the minifilter kind to something truthful such as `fim_record` so the
counters stop lying. Any option must keep `by_source_kind` interpretable,
because R-07's exit criterion depends on it.

What would close R-06: one reboot with both drivers still `RUNNING`, plus one
exercised driver rollback (stop, restore previous `.sys`, start). What would
close R-07: an agreed threshold ≥ 0.72% of burst volume (or a decision that the
number itself must be lower) plus the KIND-ATTR decision. What would close
R-08: D4 as written in `HOST-WINDOW-001` — Page Heap over ten start/stop cycles
for the #30 signature, then a 24 h soak that this session cannot outlast.

## Appendix — what this plan deliberately does not promise

1. No date estimates. A slice is done when its gate is met, not when a calendar
   says so.
2. No claim that the four stop-the-line issues are small. #25 and #28 are
   coordinated multi-layer changes; #29 and #30 need privileged host work.
3. No promise of E7. Without key custody the honest end state is a signed-less
   release with the limitation stated, and the definition of done records that
   as a declared exception rather than a pass.
