# BOOT-MODEL-003 — the zip bundle left out the scripts its own installer runs

**Created:** 2026-11-14
**Build source:** unchanged (`87e780e`); this patch touches `scripts/package_release.ps1`
and `tests/`
**Level:** E2 (10 pins, computed from the packaging sources)

---

## 1. What was wrong

Two packaging paths install this product: the NSIS installer (`tools/installer.py`)
and the zip bundle (`scripts/package_release.ps1` + `scripts/install_aegis.ps1`).
They disagreed about the boot model.

- `scripts/install_aegis.ps1:150` sets
  `$bootSetup = Join-Path $InstallRoot 'scripts\install-boot-task.ps1'` and
  **throws** when it is absent.
- `scripts/install-boot-task.ps1:24` sets `$boot = Join-Path $PSScriptRoot
  'boot-sequence.ps1'` and **throws** when it is absent, then registers the
  scheduled task pointing at it.
- `scripts/package_release.ps1` copied exactly two scripts into the bundle:
  `install_aegis.ps1` and `verify_release.ps1`.

So an install from the zip bundle on a host that has never had the NSIS build
copied the runtime, configs and drivers, created `AegisNids`, and then threw
`Boot-task installer missing`. The NSIS path ships both files with
`File "scripts\..."` directives, which is why every hand-run deployment worked
and the bundle path never did. This is the SERVICE-EXISTS-001 shape again: a
packaging path that was never the path that had been run.

## 2. What changed

`scripts/package_release.ps1` now declares one explicit payload list and fails
closed on a missing entry, instead of copying two files behind `Test-Path`
guards that silently skipped what was not there:

```powershell
$scriptPayload = @(
    'install_aegis.ps1',
    'install-boot-task.ps1',
    'boot-sequence.ps1',
    'verify_release.ps1'
)
foreach ($name in $scriptPayload) {
    $source = Join-Path (Join-Path $root 'scripts') $name
    if (-not (Test-Path -LiteralPath $source -PathType Leaf)) {
        throw "Missing script payload: scripts\$name"
    }
    Copy-Item $source (Join-Path $scripts $name) -Force
}
```

## 3. Verification

`tests/release/test_packaged_scripts.py`, 10 passed. The sets are **parsed out of
the packaging sources**, not kept in the test, so adding an install-time script
forces both packagers to carry it:

| Pin | What it refuses |
|---|---|
| bundle executed ⊆ bundle shipped | a script `install_aegis.ps1` runs by path that the bundle does not carry |
| nsis executed ⊆ nsis shipped | the same for `installer.py` |
| boot model ships as a pair | `install-boot-task.ps1` without `boot-sequence.ps1` in either payload |
| shipped scripts exist and are tracked | a `File`/payload entry naming a path a clean clone does not have |
| suffix census | a new file under `scripts/` whose type nothing checks |
| `compileall scripts` | a Python script that does not compile (54 files) |
| JSON parse | the one `.json` payload |
| text check | a NUL byte / empty `.bat`, `.cmd`, `.sh` |
| PowerShell parser | any of the 61 `.ps1` files failing to parse |
| fail-closed check | the bundle installer continuing without the boot installer |

Mutation control: deleting `'boot-sequence.ps1'` from `$scriptPayload` fails
`test_the_boot_model_ships_as_a_pair_in_both_packagers`; restoring returns 10 passed.

## 4. Limitations

1. **E2, not E4/E5.** No bundle was built and installed from this session: the
   payload list is verified structurally and every script is verified to parse,
   but "the zip actually installs on a clean host" is still the `clean_host_e5`
   gate.
2. **The invariant is about names, not bytes.** The pins prove the packagers name
   the same script files; they do not hash the copies.
3. **`verify_release.ps1` became mandatory** for the bundle (it was conditional).
   It is tracked and present, and a bundle without a verifier is not shippable,
   but this is a behaviour change for anyone packaging from a partial tree.
4. **Lab scripts stay lab scripts.** The 131 tracked files under `scripts/` are
   covered by the parse/census/evidence entry; that entry does not claim any of
   the `e5_*` / `run_*_proof` scripts was executed.
