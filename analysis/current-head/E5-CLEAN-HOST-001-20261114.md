# E5-CLEAN-HOST-001 — the last gate reduced to two commands

**Created:** 2026-11-14
**Build source:** `68a6caa` (this patch adds `scripts/`, `tests/`)
**Level:** E2 (14 pins across the preflight gate and this runbook) + verified
dry runs on the lab host
**Does not claim:** E5. The clean-host install and reboot have not happened.

---

## 1. Why this exists

Three records end at the same sentence:

- `RC-FINAL` §3 item 5 — the installer gap;
- `INSTALLER-BOOT-MODEL-001` §4 — "no clean Windows VM has run this installer and rebooted";
- `PREFLIGHT-001` §5 — "the E5 claim still requires a clean Windows host".

Each one is a *procedure* that a person has to remember to run correctly, at the
one moment when the machine is least familiar. That is how the 2026-11-11 boot
failure survived review: every service said RUNNING, and nobody checked the
order in which they had started.

`scripts/e5-clean-host.ps1` makes the procedure two commands, and makes the
second one produce evidence:

```powershell
# elevated, before the reboot
powershell -ExecutionPolicy Bypass -File scripts\e5-clean-host.ps1 -Stage Install -InstallerPath dist\aegis-installer-5.0.0.exe

# after the machine is back
powershell -ExecutionPolicy Bypass -File scripts\e5-clean-host.ps1 -Stage Verify
```

`-Stage Verify` writes `preflight-<ts>.json` (the 12 boot-model checks from
`PREFLIGHT-001`) and `soak-24h-<ts>.json` (a 24 h window anchored on a counter
snapshot, `SOAK-BASELINE-001`) into `admin-evidence/e5-clean-host-<ts>/`.

## 2. Rules the runbook enforces on itself

| Rule | Why |
|---|---|
| `-Stage` requires elevation unless `-DryRun` | a non-elevated "install" would half-succeed and leave a worse state than not starting |
| the installer hash is printed, and asserted when `-ExpectedInstallerSha256` is given | the E5 artifact must name the bytes that were installed |
| a missing installer throws before anything runs | fail closed on missing input, not halfway through |
| `-DryRun` prints every external command and changes nothing | the plan is reviewable on a host that must not be reinstalled |
| a dry run never prints `PASS` | `Invoke-External` returns 0 without running; a naive script would report a verdict it never reached |
| the soak anchor is taken **even when preflight fails** | a failed boot model is more reason to keep measuring, not less |
| exit 3 when preflight fails | the caller (a person or CI) can branch on it |

## 3. What was exercised here

| Run | Result |
|---|---|
| dry-run `-Stage Install` with the freshly built installer | plan printed, exit 0; detected `dist\aegis-installer-5.0.0.exe`, `sha256 B618AE7B…`, `6129989` bytes |
| `-Stage Verify` without elevation | refused: `this stage must run elevated`, exit 1 |
| dry-run `-Stage Verify` | plan printed, `preflight: SKIPPED (dry run)`, `RESULT: DRY-RUN`, exit 0 |
| `-Stage Install -DryRun` with a missing installer | `installer not found`, non-zero |

The installer was also rebuilt for real (`tools/installer.py --package` →
`dist\aegis-installer-5.0.0.exe`, 6,129,989 bytes), which re-proves
`INSTALLER-BOOT-MODEL-001` is buildable from current source, not just tested.
