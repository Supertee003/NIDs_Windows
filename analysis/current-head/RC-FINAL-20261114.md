## 3. Declared limitations (ship notes)

1. **Not zero-loss.** ETW admission loses 0.035 % of pushed rows in this
   window; the envelope is 3,500 queue + 4,000 shed per 24 h.
2. **Not 24 h on this exact build.** 21.77 h PASS at 21 h plus the prior
   25.33 h window; the deviation is explicit, not rounded up.
3. **Budget scope.** The daemon budget is per counter and covers
   `data_integrity`; `shed_overload` is a separate soak-tool gate. Invalid or
   negative env values fall back to 0 (strict).
4. **Write coverage is reduced by design.** Generic ETW file writes are not
   ingested; R1001/R1003/R1004/R1005 use the minifilter create/rename lane.
5. **Installer gap.** `AegisNids` is `DEMAND_START` and the loader is an
   `admin-evidence` script; `tools/installer.py` still creates `AUTO_START`,
   does not register `AegisBootSequence`, and does not write
   `AEGIS_LOSS_BUDGET`.
6. **No E7.** No signing-key custody; drivers are test-signed.
7. **One lab host.** 47.1 h combined on one Windows machine; no fleet claim.
