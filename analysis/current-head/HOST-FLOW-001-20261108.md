# PATCH-HOST-FLOW-001 — Do not mint network flows for host telemetry

## Flow contract

- **OLD FLOW:** Every source except `capture_host_net` calls `assignFlowId`; FIM/ETW/registry records with no network tuple can therefore share a fabricated zero-tuple flow.
- **NEW FLOW:** Only non-host telemetry sources call `assignFlowId`; host events continue through their existing evidence, correlation, and forensic routes.
- **INVARIANT:** A network flow ID is minted only for non-host telemetry events; event records and queue counters are otherwise unaffected.
