# L7-PATH-001 — payload does reach the matcher, but nothing joins it to a rule, and the step that should test it is broken

**Created:** 2026-11-14
**Build source:** unaffected (analysis + evidence only; no `src/`, no `build.zig`).
**Level:** E2 for what the component tests prove, E1 for the read of the code
path, and one **broken verification step** recorded as an open gap.

---

## 1. The question

`configs/Rules.json` has content rules (R0056 `' OR 1=1`, R9059 XSS, R9064
command injection, R0088 path traversal). Do their patterns ever see payload
bytes on the canonical Go-Nose path?

## 2. The path, read end to end

1. **Nose attaches bytes.** `nose/capture.go:captureAttachment` puts the raw
   frame into the v3 envelope (`V3FlagPayloadPresent`, CRC32 over exactly those
   bytes), bounded by `EventV3MaxPayload`, marking truncation rather than
   silence.
2. **Zig reads them.** `src/capture/nose_pipe_reader.zig:427`:
   `pipeline_queue.pushDecodedFrame(&frame, frame.payload)` — the v1/v2 path is
   metadata-only, v3 carries the bytes.
3. **The queue keeps them.** Pinned by
   `src/pipeline/event_queue.zig:616` — *"wire-decoded v3 frame carries payload
   through the queue gate"* — which asserts `queued.payload[0..len]` equals the
   bytes on the wire.
4. **The matcher scans them.** `src/pipeline/event_processor.zig:276-299`: for
   every event with `payload_len > 0` and a source other than
   `capture_host_net`, `active_ac.matchFirst(payload_slice)` runs, and a hit sets
   `ev.rule_id`, `kind = .signature_match` and increments
   `g_pipeline_detections`.

So by construction an L7 rule **can** match a captured Ethernet frame on the
canonical path. `zig build test` passes (exit 0), and that build includes the
queue-gate test above plus the Aho-Corasick suite.

## 3. What is still missing — two gaps

### `L7-NO-JOIN-001` — no test joins a rule to a decoded frame

The pieces are tested separately: nose encodes, the queue carries, the AC
matches. **No test loads a pattern from `Rules.json` and asserts that a frame
decoded from the v3 wire reaches `matchFirst` and produces that rule id.** The
join is the only interesting part, and it is the part nobody runs.

Consequence for evidence: L7 detection is **E2 by construction, not E4 by
observation**. No live L7 hit was observed in this session either (the sensor
here does not capture loopback, `CAPTURE-LOOPBACK-001`), so the last claim that
would matter — "a real SQLi string on a real interface raises R0056" — is still
unproven.

The proper instrument is a lab interface (VMnet) plus a benign marker payload
from `scripts/aegis_event_gen.py`'s `xss` / `command-injection` /
`path-traversal` fixtures. Note that the generator sends **synthetic metadata
events**, not wire frames, so using it as a detection proof would be a
production mock — exactly what the repository forbids.

### `BUILD-NETINT-001` — a declared verification step cannot compile

```
$ zig build test-network-integration
src\tests\federation\federation_tcp.zig:5:17: error: import of file outside
module path: '../../federation/federation_tcp.zig'
Build Summary: 0/3 steps succeeded; 1 failed
```

The step's root is `src/tests/federation/federation_tcp.zig`
(`build.zig:218`), whose module path is that directory, so its
`@import("../../federation/federation_tcp.zig")` is illegal in Zig 0.13. The
loopback TCP integration tests therefore **never run**, and the step has been
failing silently as far as the gates are concerned (the release gate does not
call it).

Smallest correct fix (one line, `build.zig`): point the step's
`root_source_file` at `src/federation/federation_tcp.zig` — the module under
test runs its own tests when it is the root — or give the test a module rooted
at `src/` and import through it. **Not applied here:** `build.zig` is in
`RUNTIME_PATHS`, and a commit there makes the running soak stale.

## 4. Verification performed

```
$ zig build test                      → exit 0 (unit tests, including the
                                        v3-payload queue-gate test)
$ zig build test-network-integration  → exit 1, error above
```

## 5. Limitations

1. **No live L7 detection claim.** E2 plus a code read, nothing more.
2. **The queue-gate test proves bytes are kept, not that a rule matches them** —
   that distinction is the whole of `L7-NO-JOIN-001`.
3. **`test-network-integration` is unrelated to L7** (it is federation TCP), but
   it is the step that would have caught a broken import, and it is broken.
4. **Both fixes need `src/`/`build.zig`**, which the open soak window forbids
   until 2026-11-15T22:20:15.
