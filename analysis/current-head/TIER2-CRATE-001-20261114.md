# TIER2-CRATE-001 — 88 brain tests and 21 Rust tests existed; no gate ran them

**Created:** 2026-11-14
**Build source:** no product source changed — this slice adds
`tests/tools/test_brain_and_crate_suites.py` only.
**Level:** E2 (6 pins, 5 of which execute real suites)

---

## 1. What was found

The test suite only ever targeted `tests/`. Two large bodies of tests lived
inside the product tree and were therefore never executed by anything:

| Suite | Cases | Before |
|---|---|---|
| `python -m pytest brain` | **88** in 0.18 s | run by nobody |
| `cargo test` — `mouth/` | 13 | run by nobody |
| `cargo test` — `aegis_dashboard/` | 8 | run by nobody |
| `cargo check` — `shield/` | compiles | run by nobody |

The brain suite is not incidental: it covers tier routing (`test_tier_routing.py`,
`test_core_routing.py`), the detection scan, the policy decision, receipts,
forensic evidence and — importantly for the detection-only claim — the
*enforcement path* (`test_enforcement_path.py`, `test_enforcement_pipeline.py`).
`mouth/` carries the Windows security monitor with 13 tests including
`receipt_tests::parses_boolean_host_effect_confirmation`, i.e. the parsing of the
very field that distinguishes observed from enforced.

## 2. What changed

`tests/tools/test_brain_and_crate_suites.py`, 6 pins:

1. `pytest -q brain` as a subprocess with `-p no:cacheprovider` (no shared cache
   file, no import-time side effect leaking into the outer process), exit 0,
   **≥ 88 cases**, and no ` failed`;
2. `cargo check --offline` for `mouth`, `shield`, `aegis_dashboard`;
3. `cargo test --offline` for `mouth` (≥ 13) and `aegis_dashboard` (≥ 8), exit 0,
   no `test result: FAILED`.

`--offline` is deliberate: a gate must not need the network, and the crates are
in the local cargo cache. A cache miss is reported as a skip, not a pass.

## 4. Limitations

1. **E2.** These are unit suites. Nothing here exercises the brain against the
   live pipe, and `cargo check`/`cargo test` prove compilation, not behaviour
   under a real security event.
2. **`shield/` has no tests** — it is `cargo check` only, and the pin says so by
   checking rather than pretending to test.
3. **The crate graph is offline-only.** If the cache is cleared, the pins
   skip; that is visible, not silent, but it means a fresh machine reports skips
   until `cargo fetch` runs.
4. **The brain floor (88) counts collected cases, not coverage.** A test could be
   rewritten to assert less while keeping the count; only review catches that.
