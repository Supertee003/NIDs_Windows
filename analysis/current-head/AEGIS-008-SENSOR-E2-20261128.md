## 2. Old flow → new flow

- **Before:** BPF string visibility was pinned, but no test fed a tagged frame into `eventFromPacket`; IPv6 extension and snaplen truncation framing were only source-supported; `pipeConn.write` was hard-wired to `*os.File`, so short-write and mid-frame error paths had no hermetic seam.
- **After:** in-memory gopacket frames exercise decode and envelope framing; `pipeConn` keeps production `*os.File` behavior but accepts an internal `pipeSink` for tests. `ensureConnected`/`sendWire` use `connected()` so a fake sink is treated exactly like an opened file for framing purposes.

**Invariant:** production still opens the named pipe via `os.OpenFile`, writes one length-prefixed frame through `writeAll`, drops the frame and reconnects lazily on a missing consumer, and drops/clears the connection on write error. No golden vector, wire byte, policy byte, counter threshold or verdict was changed.
