# Documentation lifecycle — remove, merge, archive, and keep

> Scope: build source `aa3b7b0`; records HEAD moves with records-only commits (check `git rev-parse HEAD`). The `4dd3393` labels retained below are HISTORICAL. AEGIS-PLAN-015.
> This page records the policy used for documentation cleanup and the actual
> state of the tree. It is not a source change.

## 1. Classification

| Class | Location rule | Treatment |
|---|---|---|
| Live truth | Root maps (`SYSTEM_MAP.json`, `FLOW_MAP.json`, ...), `AI_CONTEXT.md`, `AGENTS.md`, `docs/` current-facing pages | Must carry the current build source (`aa3b7b0` at the 2026-11-27 reconciliation; the `4dd3393` label above is HISTORICAL); edited only with a patch transaction and rebaselined maps |
| Historical record | `analysis/current-head/`, `docs/historical/`, `release/T20-final/`, dated `MASTER-AUDIT-*` files | Never rewritten to "look current"; carry an explicit HISTORICAL banner and their own commit |
| Local-only operator evidence | `admin-evidence/`, `D:/aegis-tmp/` transcripts | Kept outside the tracked tree; indexed by locator and SHA-256, not copied into docs |
| Generated gate boards | `docs/gates/*`, `PHASE_0_TRUTH_REBUILD_REPORT.json` | Regenerated by their tools; drift is reverted unless the regenerated content is the intended record |

## 2. Operations

- **Remove** — only unreferenced duplicates with no evidence pointer. Check
  `git grep` before deleting; an evidence pointer is a reason to archive, not
  to delete.
- **Merge** — when two current pages answer the same question, keep the one
  named by the maps and add a pointer from the other. Never merge a historical
  record into a live page.
- **Archive** — move dated records to `docs/historical/` or keep them in
  `analysis/current-head/` with a HISTORICAL banner; update
  `EVIDENCE_INDEX.json` artifact locators so they still resolve or are marked
  `missing` honestly.
- **Keep** — a page that states an open gap. Deleting an honest limitation does
  not close it.

## 4. Rule for this plan

No cleanup commit may change a provenance label, an evidence level, a build
source, or a gate result. If a cleanup would do that, it is a truth patch, not
a documentation cleanup.
